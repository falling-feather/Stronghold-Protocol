# 原版资料与当前数据

本项目以《明日方舟》的「卫戍协议：盟约」为目标，现阶段仍是原型。下面只记录已经用于实现的来源及关键差异；实际可运行数据以 [`src/config/gameData.ts`](../src/config/gameData.ts) 和 [`shared/gameRules.json`](../shared/gameRules.json) 为准。

## 干员

- [PRTS：卫戍协议：盟约](https://prts.wiki/w/卫戍协议：盟约) 给出协议阶级对应的固定练度。协议阶级与干员本身的星级是不同概念；同名干员合并后的「初始 / 精锐」又是另一维度。
- [PRTS：预备干员-近卫（卫戍协议）](https://prts.wiki/w/预备干员-近卫(卫戍协议))：本项目已采用其 Ⅰ 阶、四星、未加信赖和潜能的资料。初始使用精英 1 Lv55、技能等级 4；精锐使用精英 2 Lv50、技能等级 7。PRTS 面板计算的生命 / 攻击 / 防御分别为初始 2510 / 709 / 122、精锐 3204 / 827 / 141；攻击间隔 1.5 秒，阻挡 1；攻击天赋分别为 +4% 和 +8%。「攻击力强化·α型」分别为 45 技力、攻击 +30%、持续 20 秒，以及 40 技力、攻击 +50%、持续 20 秒。
- [PRTS：预备干员-重装（卫戍协议）](https://prts.wiki/w/预备干员-重装(卫戍协议))：四星。按同样的 Ⅰ 阶练度和计算条件，初始生命 / 攻击 / 防御为 2083 / 271 / 399，精锐为 2776 / 311 / 515；攻击间隔 1.2 秒，阻挡 3，防御天赋分别为 +5% / +10%。「防御力强化·α型」分别为 45 技力、防御 +30% 和 40 技力、防御 +50%，均持续 30 秒。
- [PRTS：预备干员-狙击（卫戍协议）](https://prts.wiki/w/预备干员-狙击(卫戍协议))：四星，按相同练度和条件，初始生命 / 攻击 / 防御为 1247 / 360 / 82，精锐为 1469 / 427 / 95；攻击间隔 1 秒，攻击天赋分别为 +4% / +8%，技能等级 4 / 7 的「攻击力强化·α型」与预备近卫一致；其速射手分支优先攻击空中目标。
- 当前将上述三种预备干员作为可选的 Ⅰ 阶原型角色；原版中预备干员还会替代玩家未持有的角色，不限于这一固定阶级。三名同名初始干员晋升时，若消耗了已部署干员，精锐会留在其中一个原位置。其余干员仍是仓库原有的虚构模板。购买费用、可抽取阵容、合并奖励和经济也仍采用项目原型规则，不能将这些值当作原版数据。

## 敌人

- [PRTS：盟约 AC-3 战场](https://prts.wiki/w/Act1autochess_m01) 中步兵的基础资料：生命 2500、攻击 280、防御 85、法术抗性 40、攻击间隔 2 秒、移动速度 1.1。
- [PRTS：宿主士兵](https://prts.wiki/w/宿主士兵)：生命 2500、攻击 250、防御 100、法术抗性 30、攻击间隔 1.8 秒、移动速度 0.9，每秒回复 80 生命。当前模拟已加入该敌人和生命回复。
- [PRTS：假想敌·铳](https://prts.wiki/w/假想敌：铳)记载其攻击 750、防御 1100、法术抗性 60、攻击间隔 4.5 秒、移动速度 0.4、攻击半径 2，且无法阻挡。该页面的常规基础生命是 120,000；项目领袖战使用 [明日方舟 Wiki 的盟约报告](https://wiki.biligame.com/arknights/盟约/S.W.E.E.P.报告)所列入门 / 标准模拟生命 225,000。当前领袖不具备原版侵蚀损伤、优先攻击高防单位和特殊技能，抵达终点后暂时停留。
- 当前波次顺序、其他敌人、地图路径与移动缩放仍为原型，尚未按原版关卡逐一还原。

## 装备与盟约

- [PRTS：盟约记录](https://prts.wiki/w/卫戍协议：盟约/PRTS盟约记录)所列Ⅰ阶装备中，本项目加入维式重锤（攻击 +10% / +20%）、坚守盾牌（防御 +35% / +60%）和口袋法阵（法术抗性 +20 / +35）。装备加成与天赋分别计算；每人可装备两件，两件同名基础装备自动合并为进阶，出售或合并干员时返还装备。
- [PRTS 帮助](https://prts.wiki/w/卫戍协议/帮助)所述原版装备占手牌区、满两件时可替换并销毁旧装备；项目目前在 5 级调度中心提供额外的两个装备商品、使用独立整备区，满两件后拒绝继续配发，也未实现替换、销毁及完整的手牌溢出。
- 现有盟约是仓库早期的手选、事件叠层原型，与原版干员自带盟约、按在场干员激活和特质叠层的规则不同；例如项目「炎佑」并非原版「炎」盟约的完整实现。当前尚未把它们标记为原版盟约。

## 系统规则

- [PRTS：卫戍协议/帮助](https://prts.wiki/w/卫戍协议/帮助) 描述每回合按整备位置重新部署、自动作战、技能就绪后通常在攻击或治疗时自动开启、自动操作的 3 秒冷却，以及重装受击等特殊策略。当前实现会在普通回合结算后恢复生命和初始技力、清除临时状态，覆盖普通攻击 / 治疗和重装受击触发；原版各分支和特定技能的特殊策略尚未全部实现。
- [PRTS 帮助](https://prts.wiki/w/卫戍协议/帮助)与 [盟约活动资料](https://prts.wiki/w/卫戍协议：盟约)记载组合联防、最终领袖战两两分组、目标生命合并及 120 秒后的扣血规则；协防连接路径、领袖的护卫编成与部分战斗细节仍是本项目简化，见 [MULTIPLAYER.md](MULTIPLAYER.md)。
- [sganggs/Stronghold-Protocol 的玩法文档](https://github.com/sganggs/Stronghold-Protocol/blob/master/docs/PLAYING.md) 是同类项目的整理资料，并非 PRTS 原始数据。当前据其记录采用按协议阶级的单人库存 `12 / 14 / 18 / 16 / 8 / 5`、同盟两倍库存、展示卡片可在库存耗尽后购买、完美作战玩家参与联防，以及淘汰时归还库存。其按存活人数倍乘领袖生命是该项目采纳的设计；本项目暂沿用此做法，不视为已由 PRTS 确认的原版数值规则。

项目使用这些资料时，应继续区分原版规则、同类项目整理及本项目的简化实现；扩充干员或敌人时应记录所采用的版本、等级和来源。
